# Contributing

Thanks for wanting to contribute! 🎉

## How to Contribute

1. Fork the repository
2. Clone your fork: `git clone https://github.com/aimages08/pos-software.git`
3. Create a branch: `git checkout -b feature/MyFeature`
4. Make changes
5. Test everything works
6. Commit: `git commit -m "Add: MyFeature"`
7. Push: `git push origin feature/MyFeature`
8. Open a Pull Request

## Code Style

- Follow Laravel conventions
- Use meaningful variable names
- Comment complex logic
- Test on Windows before submitting

## Commit Message Format

- `Add: new feature`
- `Fix: bug description`
- `Update: existing feature`
- `Remove: deleted feature`
- `Docs: documentation change`

## Reporting Bugs

Open an issue with:
- What you did
- What you expected
- What happened
- Screenshots
- Logs from `storage/logs/laravel.log`

## Feature Requests

Open an issue with:
- Use case
- Expected behavior
- Why it's useful

## Code of Conduct

- Be respectful
- No spam
- Help others
- Report issues professionally

## Testing

After setup, log in with:

- **Email:** `admin@shop.com`
- **Password:** `admin@123`

⚠️ These are default credentials. Change them in **Settings → Change Login** before deploying to production.
